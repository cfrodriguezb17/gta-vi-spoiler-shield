# Privacy · Privacidad

The extension examines text, accessible labels and nearby thread context on enabled sites on your device. It saves your preferences and downloaded catalog in the browser profile. Catalog requests carry the catalog path and, for incremental updates, the last version. They omit cookies and referrers. Removing the extension removes its local data according to the browser’s uninstall behavior.

The hosting provider handles the IP address and transport metadata needed to serve HTTPS. The API uses a short-lived in-memory IP quota. Operators can see hosting request metadata under their Railway plan and retention settings. Application monitoring summarizes load and errors. The backend sends authorized **source documents** to Gemini for the shared catalog. Site cards viewed by a user stay on their device.

La extensión procesa en tu dispositivo el texto de las publicaciones, las etiquetas accesibles y el contexto del hilo. Guarda las preferencias y el catálogo en tu perfil. La sincronización solicita el catálogo con su versión y omite cookies y referencias de navegación. Railway recibe la IP y los metadatos de conexión. La API usa la IP temporalmente para limitar solicitudes. El backend envía a Gemini los documentos de las fuentes autorizadas que alimentan el catálogo.
