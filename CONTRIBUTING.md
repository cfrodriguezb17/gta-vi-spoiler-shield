# Contributing

Use a branch and open a pull request against `main`. Include the behavior you changed and the checks you ran. Use fictional events in tests, issues and screenshots to keep discussion spoiler-free. For adapter changes, include the site, browser and a minimal synthetic card.

Follow the [development guide](docs/development.md). Changes to the API or deployment should update the [API contract](docs/api.md) or [runbook](docs/operations.md). Report vulnerabilities privately using the [security policy](SECURITY.md).
