# Security

Use [private vulnerability reporting](https://github.com/cfrodriguezb17/gta-vi-spoiler-shield/security/advisories/new) for security or privacy issues. Include the affected version, browser, expected behavior and impact. Redact account details and credentials. The latest published release receives fixes.

Production credentials belong in the relevant Railway or GitHub environment. The extension downloads catalog data over HTTPS. Its executable code, font and WebAssembly are packaged locally.
